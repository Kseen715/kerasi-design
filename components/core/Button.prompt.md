Action button; one primary per view, everything else secondary/ghost/quiet.
```jsx
<Button variant="primary" iconRight="arrow-right">Start a project</Button>
<Button variant="secondary" size="sm" icon="git-fork">Fork</Button>
```
- `variant`: primary (accent fill, chamfered corners) · secondary (1px ink outline, inverts on hover) · ghost · quiet (text link style)
- `size`: sm 32 · md 42 · lg 54. Labels are Oswald uppercase.
