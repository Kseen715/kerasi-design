Kerasi favicon / project glyph for browser tabs, project switchers and app icons.
```jsx
<Favicon size={16}/>
<Favicon variant="sub" label="H" color="crimson" size={32}/>
<Favicon variant="sub" label="Gt" color="graphite"/>
```
- Main mark is a dedicated simplification (5 shapes), not the full logo scaled down.
- Sub tiles: the blossom-pink crown on top is the family identifier; tile colour + letter identify the subproject. Keep one colour per subproject.
- For real `<link rel="icon">` files use `assets/favicon/*.svg` or export PNGs from `guidelines/favicon-builder.html`.
